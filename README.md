# Breath of the Wild Cemu Graphic Packs

本仓库收录《塞尔达传说：旷野之息》的 Cemu 图形插件，来源于官方图形包并加入本地化内容。

## 内容

- `src/BreathOfTheWild/`：官方 Breath of the Wild 图形插件
- `src/BreathOfTheWild/Mods/AllMapLocations/`：显示地图上全部呀哈哈和神庙的插件
- `src/BreathOfTheWild/汉化/简体中文/`：简体中文语言包
- `src/BreathOfTheWild/汉化/繁体中文/`：繁体中文语言包

将 `src` 目录中的内容复制到 Cemu 的 `graphicPacks` 目录即可使用。语言包位于 BreathOfTheWild 内的“汉化”分类中。
